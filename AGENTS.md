# Tilbudsplan

Produkt: gode, gjennomførbare middager til lavere reell handlekostnad. Ikke bland inn Ukeplan, Ludus eller Hermes-spesifikk arkitektur.

- Bevar eksisterende Sites-prosjekt og Git-historikk. Offentlig GitHub-kode betyr ikke offentlig profildata eller offentlig nettsted.
- Personlig lagring er D1-basert. Ikke erstatt den med localStorage. Profilnøkkel kan huskes lokalt, men må aldri legges i logger, delingslenker til venner eller Git.
- Vis prisusikkerhet. Ikke kall anslag normalpris eller besparelse, og ikke gjør gamle data aktuelle ved å oppdatere hentetid.
- Alle retter trenger mengder og fremgangsmåte. Handlelisten må også inkludere ingredienser uten tilbud.
- Kategorier for sunnere/lettere mat er preferanser, ikke medisinsk veiledning. Ikke lov vektnedgang eller allergisikkerhet.
- Kjør `npm test` og `npm run build` før publisering. Ikke endre allerede anvendte migreringer.
- Kilde- og lagringsfeil må vises tydelig; aldri gi melding om vellykket lagring før serveren har bekreftet det.
